# Snippet organization

No snippets are present yet. Add a language folder only when you have an example to commit.

Use this convention:

```text
snippets/<language>/<descriptive_filename>.<extension>
```

For a multi-file example, use `snippets/<language>/<example_name>/` with its own README. Keep examples small enough to understand independently; document required inputs and expected output. Avoid relying on absolute paths specific to one computer.

See the [documentation template](../templates/snippet.md).
